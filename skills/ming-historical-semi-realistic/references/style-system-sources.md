# 完整视觉体系来源

核查日2026-10-01。包为公开作品观察与制作方法之上的原创规范，不是第三方内部美术圣经、角色模型、材质球或官方Skills。

## 整体作品方向

- [阅文官方斗破EP01短预告](https://www.youtube.com/watch?v=UnGvasWYcmE)：实际浏览器打开，核对“阅文动画官方频道 Yuewen Animation”与验证标记，暂停观察近景角色、衣料和室内暖光。只取统一塑形与照明；此为较早素材，还结合此前年番三海报观察（style-observation.md），不说某版本代表全系列。未复制脸型、玄幻服装或角色素材。
- [官方EP208预告](https://www.youtube.com/watch?v=bVWEmMaU_Pk)：实际打开，同一发布者，观察0:10—0:17环境与特效，此段不作为面部细节依据，不将宫殿紫光套入贫县。
- [SMG官方幻维介绍](https://www.smg.cn/review/202504/0166369.html)：读取官方文字，只确认制作方相关作品与全流程能力；不据此推断软件、头身比或精确渲染参数。

## 成套制作方法

- [Blender Studio完整人物工作流](https://studio.blender.org/training/realistic-human-research/)：读取官方搜索索引的说明与目录，正文直接打开受限。目录含设计雕刻、拓扑层、面部形状皱纹、衣服、烘焙及修改。取结构先于纹理、面部服装分工及表情形状组织；不称读完课程，不等同国漫风格。
- [Filament官方PBR文档](https://google.github.io/filament/main/filament.html)与[GitHub](https://github.com/google/filament)：实际读取材质/照明分离、粗糙度及材料光照成像目录，仓库标Apache-2.0。仅原创提炼材料区别，未运行代码、下载示例人物，未声称Seedream使用其引擎。
- [腾讯Hunyuan官方提示词手册](https://github.com/Tencent-Hunyuan/HunyuanVideo-1.5/blob/main/assets/HunyuanVideo_1_5_Prompt_Handbook_EN.md)：实际读主体、景别、光向、色温、风格和可见细节的组织方法。项目不切Hunyuan，支持能力以Seedream/Seedance真实接口为准。

## 取舍和许可

影视图像与馆藏只保留链接，不上传模型、不打包再分发。生成候选通过授权的项目媒体API。明代史料及其读取局限仍见 ming-aesthetics.md；本包色板、骨相与验收为原创设计，与来源观察分开。
