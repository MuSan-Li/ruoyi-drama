# GitHub 短剧技能适配包

本包将十个 GitHub 仓库的制作方法接入 RuoYi Drama，提供十五个后台可维护技能。每个条目含分类、适用范围、项目适配正文和来源登记。七个许可明确的仓库另保留入口源码快照；其余三个仅记录来源并提供自主编写的方法，不收录上游全文。

| 分类 | 技能 |
| --- | --- |
| 编剧风格 | ZenStory 分阶段制作、说好小说改编、微短剧选题与分集 |
| 导演风格 | 故事转分镜与段落交接、Seedance 多模态提示词、一致性与续段、表演摄影声音、漫剧空间动作表演、Seedance 案例导航 |
| 视觉风格 | 电影写实、三维 CG、二维手绘、漫画运动、动漫动作、影视风格方法库 |

`catalog/` 是本包技能的分发源，后台打包副本位于 `ruoyi-chat/src/main/resources/short-drama/skill-catalog/`。应用发现其中的 manifest 后，只初始化运行目录中尚不存在的同名技能；已有后台编辑、停用状态和历史备份保持。后台运行目录仍是实际当前内容的来源。

技能市场按后台分类展示全部正文和来源；后台“智能体管理 → 技能管理 → 制作技能”可以筛选、阅读和维护。创作页面只选编剧与导演，每类一项；视觉在资产配置中选择后保存，用于后续图片生成。默认方法与项目显式选择分别管理。旧分类兼容读取，正文和来源保持可追溯。

`default-methods/` 中的三份方法经后端已有业务技能加载器按阶段复用：剧本阶段加载改编证据与叙事承诺，分镜及提示词阶段加载素材职责与镜头接点，审阅阶段加载状态区分与最小返修。默认方法不携带整套上游手册，不增加媒体提交路径；具体风格仍按当前项目选择。

所有适配都沿用本项目的原对白、连续导演描述、独立 timing、首帧可选、真实模型目录及内容审阅。不沿用来源的固定镜长、逐秒清单、固定集数或自动付费任务。具体效果仍需实际素材和成片检查。

固定提交、许可、快照文件与 SHA-256 见 `sources.json`；分发条目与正文哈希见 `catalog.json`。`upstream/` 仅保存入口快照，可能缺少原文相对引用的文件，不作为完整 Agent 安装包执行。

分发到后端可运行 `python scripts/sync-drama-skill-pack.py --backend-root <ruoyi-ai目录>`。已有文件与分发内容不同会停止并指出差异，需先回收后台或后端的修改；该命令不修改运行目录、不覆盖历史版本、不调用模型或生成媒体。`--check` 只核对分发一致性。
