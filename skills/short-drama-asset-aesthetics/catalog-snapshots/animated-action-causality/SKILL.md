# 动画动作 · 因果调度

适合有明确主角选择、危机与可见结果的动画短剧。每段先建立目标、阻碍、空间关系，再让动作造成结果，最后用对手或听者反应确认转折。每个镜头以一项主要叙事任务为中心，减掉重复解释，不能删掉原文因果、参与者或关键道具。

主角掌控局面时镜头稍舒展，让观众看清成果；遭遇威胁时缩短无关停顿，以景别和声场集中判断压力，但正常对白、交换物品和危险动作仍有合理时间。爽点是角色解决原本的问题并付出已定代价，不无原因添加胜利或能力。

动作段落先建立人物、危险、目标之间的位置和摄影轴线。人物从实际首帧0秒姿势起步，动作有准备、执行、收束；不给未来动作提前摆好姿势。听者反应要有明确触发，旁白、心念、画外和画内嘴型各自对应原声源。

成长蒙太奇可重复相似机位，依靠季节、年龄、服装和空间阶段呈现变化；不把多年成果压成一天，也不只用口述报告成果。末帧停在本镜结果，下一镜接住持物手、光向、伤势和位置。详细逐秒导演稿、原对白与默认审阅规则优先。

这是本项目原创提炼的执行方向，借鉴公开访谈的叙事方法，不复刻现成电影人物、画风、桥段，不代表某位导演批准。
