# 审美与导演技能目录快照

这些目录来自实际后台已保存、已回读的五个技能。`manifest.json` 指定类型、标题、描述和启用状态；`SKILL.md` 为内容正文；`references/` 与 `scripts/` 为附属文本。脚本不会因读取技能而自动执行。

日常维护入口为 ruoyi-admin 的“短剧制作 → 审美与导演技能”。运行目录是 ruoyi-ai/data/short-drama-skills；完整备份还须包含该目录的隐藏历史版本。这里保存可供版本管理的分发副本，不替代后台当前版本；回收后台修改时核对内容版本，不直接覆盖已经有人编辑的副本。

初次安装可将一个完整目录放到已配置运行目录的同名路径，再通过正常技能接口回读类型和内容版本。已有目录先备份，避免覆盖管理界面的修改。项目通过稳定技能标识引用，不以标题字符串识别。
