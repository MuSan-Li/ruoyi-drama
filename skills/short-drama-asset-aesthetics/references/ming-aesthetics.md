# 明代资产审美参考笔记

核查：2026-10-01。用于国风三维动画的美术提炼；以下区分馆藏/研究结论与本剧的设计选择。不是服饰复原报告，也不能用模型生成图证明历史正确。

## 先定身份与穿着场合

故宫的[明代官员服饰研究](https://www.dpm.org.cn/Uploads/File/2019/11/25/u5ddbb3f9e989e.pdf)将朝服、公服、常服等分开讨论；其检索摘要明确描述常服乌纱帽为前低后高、左右有翅，并说明常服与补子的关系。本次 PDF 正文打开超时，不能据此给所有时期规定唯一帽翅角度或裁片尺寸。

朱承晏的日常县令形象采用“乌纱帽、闭合圆领长袍、革带、黑布靴”的清楚轮廓；主色沿用已定的石青，既避免全身灰泥，也便于在暖土城墙前识别。**这是剧中美术定案，不宣称七品所有场合只能穿这一颜色。**公服品色与常服补子不是一个维度，不能把两张表直接混成一套。七品文官应核查鸂鶒而不是仙鹤、麒麟或龙；未核清图样时先做简化胸背方补候选，确认后固定，不用“金色凤凰”含混替代。

补充的可靠实物页：[台北故宫明中叶蓝地织金狮纹方补](https://south.npm.gov.tw/SelectionsDetailC004100.aspx?Cond=dbcee5af-d934-4d50-8cc3-039edfea36ec)明确说明乌纱帽、团领衫、束带属于日常视事常服；并指出明代补子通常较清代大、直接织绣在袍上。**这里只取位置、尺度和织绣关系，不能给县令套狮子纹。**样板不要做成清代开襟两半补子、贴上去的小徽章或现代胸牌。远景读得出鸟纹方形，近景才读细节；简化细节不等于缩成领口硬徽章。

故宫[带板](https://www.dpm.org.cn/lemmas/239465.html)检索结果给出六、七品用银的制度线索；本次条目打开失败。样板可采用暗银色小带板，不能直接画帝王玉带或满腰大金牌；具体数量、尺寸、晚明实际穿用仍待进一步实物核对。

## 服装结构要写进提示词

| 项目 | 样板可执行描述 | 要避免 |
| --- | --- | --- |
| 圆领官袍 | 闭合圆领、领口贴合颈根、暗色内缘、肩线平顺、宽袖有重量、革带在腰上、袍下摆自然垂落 | 深 V 开胸、现代西装领、紧身皮甲式腰身、四处漂浮飘带 |
| 乌纱帽 | 帽体前低后高、黑纱细织、两侧短而明确的帽翅、与头围贴合 | 清代圆顶红缨/顶珠、皇冠、宋式极长水平展脚、仙侠发冠 |
| 铁生工作服 | 棉麻交领右衽、窄袖/收袖便于劳动、外加完整旧皮围裙、系带有受力逻辑、下摆不拖入炉火 | 袖口开到肘上仍被称传统短衫、时装拉链、遍身无原因破洞 |
| 周慎差役 | 皂色厚布、收敛袖口、稳重腰束、耐用布鞋；左颊疤和铁尺区分身份 | 把普通差役套成锦衣卫飞鱼服、麒麟补或全身金属护甲 |
| 普通乡民 | 米白/靛蓝/赭褐的棉麻，简朴但结构完整；补丁只在肘、膝、下摆等磨损处 | “贫穷”全部变成灰黑泥脸、衣服条条破烂、每个人相同脸和衣色 |

上述平民/差役的具体配色和收袖属于动画设计选择。本次尚未取得鲁西南 1639 年差役制服的直接实物证据，不能称为统一官定款式。交领右衽需要检查叠襟方向：穿着者左前襟覆盖右襟，向穿着者右侧系合；审图时不要被镜像反转误导。裁片尺寸、袖型细分有待新增可核实出土服装资料；不编数字。

## 人物要漂亮，也要能区分

本剧设计建议：朱承晏用清晰眉骨、不过分尖削的下颌、略宽于网红脸的颧区、明亮但不过大的眼睛；铁生用更宽鼻翼、较厚眉、圆方脸、劳动形成的前臂，保留年轻感；周慎用较长中庭、眼睑褶皱、短须/口周质感和左颊旧疤，不把年龄只画成白头发。这些是原创造型方向，不能以某位演员或某个现成游戏人物为模板。

国风三维应保持脸颊、鼻梁、颌角的体积，面部阴影简化、眼睛有清楚反光、皮肤柔和而不蜡；头发大束先成型，再做少量鬓角碎发。棉麻以漫反射为主，绸面只有窄而柔的高光，皮革较硬且磨损局部，铁件呈暗灰冷反光，铜件为局部暖褐，不能所有材质都像湿塑料。

渲染组织参考 [Unity 官方 Toon Shader](https://github.com/Unity-Technologies/com.unity.toonshader)：基础色、一级阴影、二级阴影分别控制，角色受环境光影响有明确边界。[JTRP](https://github.com/JasonMa0012/JTRP/blob/master/README.md)把脸、头发、轮廓和环境光分别处理；可借鉴“分材质定义”，不要求把本项目换成 Unity 渲染器。NiloCat 的 [URP Toon 示例](https://github.com/ColinLeung-NiloCat/UnityURPToonLitShaderExample)是学习用简化实现；README 中商业完整版截图不是开源示例拥有全部效果的证据，也不是可直接复用的角色素材。

## 器物与县城：贫而有秩序，繁而有层次

故宫[明代四出头官帽椅](https://www.dpm.org.cn/collection/gear/229330.html)可取简洁结构：搭脑和扶手出头、弯曲靠背、藤座、圆腿与管脚枨。馆藏为高档黄花梨；本剧贫县改用本地普通木材和朴素修补，保留构造，不照搬昂贵材料与宫廷陈设。

县衙场景建议三层：前景一个能说明正在办事的木案角、纸卷、砚；中景完整桌椅与可走动空间；后景土灰墙、木柱、简洁格窗和少量账册。以木色/灰瓦/土色为大面积，石青服饰作为人物主色，暖纸/暗铜形成小面积点睛。不要每寸布满花雕，也不要删成只有一堵脏墙。

[国博《南都繁会图》](https://www.chnmuseum.cn/zp/zpml/csp/202010/t20201028_247938.shtml)有街店、职业人物、招幌和商业组织；馆方明确其并非仇英亲笔。可学身份与店铺功能分层、街道前中后关系，不能把明代南京繁华大城市完整套进青芜贫县。国博还说明画中衣色鲜艳，说明“明代所有人只能灰黑”并不成立；并非证明贫县也能人人绫罗。

[国博宣德铜熏炉](https://www.chnmuseum.cn/zp/zpml/csp/202008/t20200826_247450.shtml)可取沉稳器型与褐色铜表面的材料关系；它是礼器/精工器物，不能据此把每户油灯都变成华贵香炉。铁生工坊优先石/土炉座、粗木工作台、夹钳、炭筐、铁件半成品，按使用位置摆放，不能随意悬浮或把锤子画成兵器。

1639 的低旧土城墙、局部砖垛与 1644 成熟防御设施必须分版本。地域为鲁西南运河支流，避免整城套白墙马头墙的江南水乡模板，避免宫殿重檐、巨城红墙琉璃瓦。季节、时间、建筑成长阶段和装备数量与原生产清单共同审阅；审美升级不能悄悄改剧情年代。

## 长期维护

每次只新增能改变一个具体判断的资料。来源记录要有原始 URL、来源性质、核查日期、实际读取程度、许可核实状态、适用身份/年代/地区、可复用观察、局限；博物馆公开网页不等于图像素材获得再分发授权。只保留链接和原创提炼，不打包馆藏照片或 GitHub 示例人物。

维护一组正/反样板：同一角色正侧面与服装细节、同一地点白天/夜晚、器物比例与材料。记录用户选中/退回及具体原因，再更新提示词与审图表。未确认的生成图只保留候选；先修形制和身份，再调配色光影，最后微调纹理，避免用“精美、电影级、8K”替代造型决策。
