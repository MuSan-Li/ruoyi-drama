# RuoYi Drama 通用 UI

以白色和蓝色为主。工作台承载持续增长的剧本、角色、形象、声音和分镜资料，优先保证总览可扫描、详情可阅读、操作可定位。

## 视觉规范

统一变量维护在 `src/styles/studio.scss`，由 `src/styles/index.scss` 引入。新增页面和组件使用变量，不单独定义主题色。

| 用途 | 变量 / 规则 |
| --- | --- |
| 主色与交互 | `--drama-primary`，蓝色 `#2563eb`；悬停 `#1d4ed8` |
| 工作区背景 | `--drama-canvas`，浅灰蓝 `#f4f7fc` |
| 卡片 / 弹窗 | 白色 `--drama-surface-strong`，浅色细边框 |
| 次要区域 | `--drama-surface-muted`；选中区域 `--drama-primary-soft` |
| 正文层级 | `--drama-text` / `--drama-text-secondary` / `--drama-text-tertiary` |
| 状态 | 成功、警告、失败使用独立语义色，仅用于状态提示 |
| 间距 | 4、8、12、16、24、32px；卡片间距通常 20px |
| 圆角 | 6px 控件 / 10px 内部区域 / 14px 卡片 |
| 字号 | 页面标题 22px；角色名 20px；区块标题 16px；正文 13px；辅助信息 11–12px |

Element Plus 保留表单、选择器、弹窗和键盘行为，通过共享变量及统一控件样式接入主题。主操作使用蓝色填充，次要操作使用白底描边，文字操作用于低优先级入口。

下拉框统一使用 `--drama-control-border` 的 1px 浅灰边框，悬停采用 `--drama-control-border-hover`，聚焦只变为细蓝框，不叠加描边阴影。禁用态使用浅灰底，校验失败仍使用细红框。原生 select 与 Element Plus Select 共用此规则；组件只设置业务所需宽度，不另写边框或默认聚焦外圈。样式入口先加载 Element Plus，再加载工作台主题。

## 可复用组件

- `StudioSection`：统一标题、说明、眉题和操作区；操作区支持换行。用于资产工作区和角色档案区。
- `StudioBadge`：`neutral`、`accent`、`success`、`warning` 四种状态；可附带状态圆点。避免把年龄、性别等普通信息全部做成彩色标签。
- `StudioDisclosure`：默认折叠长说明与次要设置，保留内部编辑值；编辑模式可默认展开。用于形象提示词、人物设定和场景资料。
- `GeneratedAssetImage`：沿用项目图片预览与鉴权能力，支持 `interactive` 与 `fit`。置于可点击卡片或外层预览按钮内时关闭内部交互，避免按钮嵌套。

通用组件只接收展示数据与插槽，不提交生成任务或修改业务数据。业务保存、图片选用、撤销、删除、任务轮询继续由原流程处理。

## 角色卡与档案

`CharacterLibrary` 负责搜索、层级筛选、角色总览及档案侧栏。页面通过 `appearance` 插槽提供形象操作，通过 `edit` / `save` 事件沿用原提示词保存逻辑。

总览只展示人物图、角色名、角色层级、性别年龄、服饰等级、两行简介和少量性格标签。角色图采用完整显示，不裁掉全身衣装；无图、参考图、候选与已选用图片分开标记。

档案侧栏按以下顺序展示：

1. 人物形象与基础身份。
2. 完整人物设定。
3. 按换装 / 状态切换的形象版本，含提示词、参考图、图片候选及原生成入口。
4. 默认折叠的角色声音卡；实际绑定状态来自原声音接口。

查看形象版本只改变当前浏览位置，不修改选用图片。图片仅在点击原“选用候选”入口后持久化。总览优先显示已选用版本；原参考图不冒充已选用图片。图片索引与已有媒体均保留。

声音编辑器按角色缓存，切换角色后可返回继续编辑；切换项目时清理缓存。样音生成和试听继续使用原声音组件。

## 内容密度与响应式

角色、场景、道具按制作顺序排列。场景先展示名称、简要说明和预览，详细资料与制作控件默认折叠，编辑模式展开。

工作台项目侧栏与主内容分别滚动；角色网格根据可用宽度自动换列。窄屏改为单列，项目列表横向浏览，档案侧栏占满视口，控件允许换行。长标题、说明和版本名不能撑宽整个页面。

滚动条在全站共享样式：透明轨道、浅灰蓝圆角滑块，悬停加深。Chromium 轨道宽 8px、滑块可见宽 6px，Firefox 使用 thin；Element Plus 自绘滚动条使用同一颜色与 6px 宽度。纵向、横向、文本编辑区和弹窗均沿用此规则，不另加深灰粗滚动条或箭头按钮。

新增区块应遵循“标题与摘要 → 内容预览 → 详情与操作”的层级。优先减少同时展开的内容，避免每张卡片直接堆叠所有原生表单。

工作表单只常驻显示字段名称、真实内容、必要进度和操作入口。移除重复的流程解释、自动估算的“待检查”标签、技术状态码和任务编号；可选项在标签中注明，示例放入输入框占位文字，长资料通过主动展开查看。失败操作仍显示具体原因，不能以删除提示为由标记成功。参考图与首帧等自动读取失败使用本区块的重新读取入口，不堆叠通用网络报错；没有道具绑定的镜头不请求道具参考数据。

## 分镜视频与规划设置

分镜方式只在尚无分镜的资产配置页显示，生成分镜时自动保存并回读。默认方式明确显示为选中项，不展示冗余说明和绑定按钮；已有分镜后隐藏此设置。

`ShotVideoPanel` 统一镜头视频的状态、播放、查询及操作插槽。状态只显示一次，完成状态使用蓝色标记，播放与保存、重新生成在同一张白色卡片内；不在正常流程展示任务编号。任务编号仍在原任务记录中保存，查询与恢复同一请求的业务逻辑保留。

`LocalVideoPreview` 点击后打开独立播放器，按需通过项目鉴权读取既有视频，不在表单中的状态横条内撑开。弹窗包含完整画面、原生播放控制及下载入口；关闭后移除视频节点以停止播放，切换镜头或卸载时取消旧请求并释放临时媒体地址。
