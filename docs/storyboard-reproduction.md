# 分镜格式与整集复现

普通“生成分镜”入口会加载默认 `cinematic-storyboard`、`video-prompt` 和内容审阅规则，再结合项目选择的导演风格。编剧风格负责剧本阶段；视觉风格在资产配置中决定图片方向。无需在每个镜头手动粘贴整份技能。

## 工作台操作

1. 在项目中保存完整、已确认的剧本。只重做分镜时保留正文和对白，在“制作与修订要求”中写明整集或具体范围、允许使用的角色形象阶段、哪些候选尚未选用。该字段现在与世界观一起进入规划上下文。
2. 创作技能各选一个：编剧风格、导演风格。本次使用“微短剧 · 选题、人物与分集”和“Seedance · 表演、摄影与声音”。其他题材可以换风格，默认导演稿格式仍生效。
3. 在资产配置中确认角色、场景、道具和角色样音。沿用资产时保留原图片及选用版本，不因重新分镜重复生成；重设计候选须明确选用后才作为本次参考。
4. 点击“生成分镜”。规划按场组织动作和对白，细化写入下述段落格式。视频秒数默认不指定；时长估算保留在 `timing`。首帧可选，未使用时从起始构图规划展开。
5. 阅读整集分镜，核对每一场的事件和对白、衣装变化、出入口、持物与末态。结构或字段检查通过不代表内容审阅或视频验收通过。局部问题修对应镜；反复问题更新责任技能，再验证普通生成入口。
6. 保存后重新读取项目，核对剧本版本、技能版本、镜头数量、资产索引与媒体任务。在分镜下方“参考图”实际查看关键道具缩略图：显式 `visible_props` 优先；未设置时按道具卡“关联镜号”读取。只确认资产库里有图或链接能打开，不代表当前镜头已经显示或绑定。旧项目只有在用户明确要求删除、且新项目完整核对通过后才删除；原版本和媒体关联先备份。

## 每段提示词的固定格式

```text
【起始构图】本段开始时的空间、人物位置与姿态、衣装阶段、持物和既有动作状态。

镜头1：景别与机位，顺着原文写动作发起、受力或接触、结果与回应；把原话及声源安排在实际动作之间。

镜头2：仅在本段确有必要切镜时出现，继承前镜动作状态，继续同一时空的事件。

当前空间为……。具体光源、必要材质、环境与动作声、对白口型规则，最终姿势、道具位置和切出点。
```

确实采用并审阅首帧时，将开头替换为“【首帧实况】”，内容必须与实图一致。单镜也从“镜头1”开始，不为了格式增加第二镜。不把逐秒表、分辨率或技能全文混进导演稿，不复制参考案例的人物与剧情。正文保存真实空行，工作台默认阅读排版、展开与复制保持这些段落。

## 可复用检查

将 `GET /short-drama/{projectId}` 的 `data` 保存为 `detail.json` 后，可以运行：

```powershell
python -X utf8 skills/causal-storyboard-production/scripts/review_episode.py detail.json --output review.json
```

脚本只读本地文件，报告原对白字面顺序、逐镜声源待查项、重复引用、场次分布、格式、资产索引与候选引用，不修改项目或提交媒体。原话分在动作前后的引号内时可识别为同一句；同义改写、真实声源和跨镜因果仍需人工核对。视频生成后的动作、口型、声音和画质另外验收。

复现记录包含：原剧本及版本、制作要求、资产选用、编剧与导演技能名称和完整版本哈希、默认规则版本、实际写作模型、入口和审阅结果。相同配置可复用同一方法与格式；生成模型不保证逐字相同。

## 规则维护位置

- 后端默认规范：`ruoyi-chat/src/main/resources/short-drama/skills/video-prompt/SKILL.md`、`cinematic-storyboard/SKILL.md`、`director-review/SKILL.md`。
- 可选导演风格源：本仓库 `skills/github-short-drama/catalog/github-seedance-directing/SKILL.md`，与后端 `short-drama/skill-catalog` 同步。
- 可选编剧风格源：`github-short-drama-writing/SKILL.md`，保留已定稿剧本的阶段边界。
- 当前运行的可编辑技能：通过 `/short-drama/skills/{name}` 读取，更新必须携带 `expectedVersion` 并回读。修改源码不会自动覆盖已维护的运行时版本。
- 修改内置技能后需要更新运行包并重启后端；记录 `ShortDramaDirectorSkills.VERSION` 和源码摘要。模型仍只收到本镜已提炼的导演稿及真实素材绑定，不附整份手册。

本次默认规则版本为 `director-video-prompt-v16`。细化输入增加原场次时间上下文，角色档案按逐镜选中的形象传入，避免从其他衣装或场景母图带入错误天气、服装和伤势。对白审阅包含带标点的内心声和无引号对白。默认输出示例同样使用固定三部分，避免模型仅遵循一句泛化的“连续导演描述”。

铭牌等画面文字与实际对白分别处理；没有原文朗读动作时，不分配声音、口型或说话时长，也不在视频执行时自动补读。

《青芜长明》的具体项目、完整技能哈希、原始生成回执及最终核对记录保存在 `output/qingwu-e01-rebuild-20261006`。本次经过原生规划、逐场编辑审阅、正常检查点恢复与细化、整集修订和回读；个别模型输出仍需内容审阅，不能以规则或结构校验代替审稿。
