# 登录提示与会话时长

短剧工作台与 RuoYi AI 管理后台使用统一账号。接口发现未登录或登录已失效时，统一提示一次“请先登录”并返回登录页；并发请求、迟到响应、上传下载和事件流使用相同的登录恢复流程。重新登录后，可以继续操作。

PC 管理后台及 Web 工作台客户端的无操作超时为 **12 小时（43200 秒）**，由后端 `sys_client.active_timeout` 控制。固定有效期由 `sys_client.timeout` 单独控制，默认仍为 7 天。

在后端“客户端管理”修改 token 活跃超时时间为 `43200` 后保存，会同步清除客户端缓存。已签发令牌继续使用签发时的策略，需要重新登录才能应用新时长。

现有数据库可使用后端 `sql/pc_login_idle_timeout_20261002.sql` 迁移原 30 分钟的 PC 策略；直接执行 SQL 后还需清除对应客户端缓存。迁移保留已自定义的客户端超时设置。

未登录属于正常认证状态，后端认证处理器使用 DEBUG 日志记录，并返回业务码 `401` 和提示“请先登录”。修改后端处理器后需部署或重启后端服务。
