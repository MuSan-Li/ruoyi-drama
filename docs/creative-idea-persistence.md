# 原始创作输入保存

项目的`originalIdea`独立保存用户输入，`description`继续保存生成后的项目概要。
新建剧本的同步和流式入口均保存原始`idea`正文；标题、技能和剧本润色不会拿概要或新剧本覆盖它。
加载或切换项目时，第一步从当前项目的`originalIdea`回填，不沿用另一项目的输入。

已有项目可在第一步使用“保存想法”。保存后回读核对正文，只更新项目输入，不生成剧本、图片、声音或视频。
“生成草稿剧本”仍是单独的创作操作。

后台字段由配套仓库的`docs/script/sql/update/2026-10-03-short-drama-original-idea.sql`幂等添加，新装数据库模板也包含该字段。
升级前没有保存的输入不以生成概要冒充原文；仅在找到原始请求记录时精确补回。
恢复旧输入时只更新`originalIdea`，保留已有剧本版本、分镜、资产和成片；原始请求与恢复回执留在本地，不随代码发布。
