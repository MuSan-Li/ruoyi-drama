# 上美影水墨淡彩：推文与教程

以已有《小蝌蚪找妈妈》57 秒对白样片介绍审美与工作台流程。

- [推文正文](article.md)：开发者视角，以宣纸留白、墨色浓淡、色盘与动物造型为主线。
- [操作教程](tutorial.md)：配置、技能登记、想法、剧本、资产、声音、分镜、视频检查与合成下载。
- `images/`：14 张 1920×1080 完整工作台截图及 3 张成片实帧。后者为 1080p 合成文件抽帧，源生成视频是 720p，不作为原生分辨率证明。
- [发布包构建器](build_publication.py)：只使用本地文稿、现有图片与视频，生成内嵌图片的 HTML、独立正文和 ZIP，无模型调用。
- [录屏教程讲解稿](video-narration.md)：10 个操作与审美章节，片尾接已有 57 秒样片，保留原对白和水声。
- [视频制作说明](video-production.md)：真实页面录制、讲解字幕、素材保留及复现方式。

```bash
python docs/tutorials/smy-watercolor/build_publication.py
```

发布结果在 `output/smy-article/`，正文可单独复制富文本、下载 HTML，图片可打开原尺寸。存在本机案例视频时会复制为 `sample.mp4` 并加入发布包；在其他机器构建时需要提供该视频，或只发布图文。

参考会话「制作短剧教程并更新项目说明」提供交付方式：开发者口吻、按功能讲解、高清完整页面、可复制富文本。审美与案例来自本项目的上美影水墨淡彩版本，未沿用参考会话的真人影视画风。

截图过程仅查询与浏览已有项目，原始输入、剧本、资产、声音、分镜和成片前后相同。没有重新提交媒体任务。完整读取记录和验证回执保留在本地 output，不包含在发布包中。
