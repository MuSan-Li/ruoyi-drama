# 白蓝主题｜电影感古装短剧制作教学

用户授权制作推文及配音视频教学；参考聊天 `codex://threads/01a0fd54-04aa-7a62-9bc5-fd7173124218` 的真实页面录屏、FFmpeg剪辑、普通话合成讲解与中文字幕形式。

案例为现有《长安异闻录》第一卷·算命项目，ID `2106381114532110337`，影片原片720p。参考作品及原始视觉资料来自Rick在LibTV公开的项目，推文保留来源链接。教程强调本案例至少采用Seedance 2.5，型号选择不等于整片达到行业电影质量验收。

源文件：

- `article.md`：推文，真实制作叙述与实际截图。
- `video-narration.md`：11章普通话讲解稿。
- `produce.py`：取证、截图、配音、真实页面录制、白蓝剪辑与发布包构建器。
- `review.py`：发布页交互、配音文本覆盖、编码实帧、语音内容抽查与推文四层编辑检查。
- `images/`：1920×1080实际页面截图及来自720p影片的成片实帧。

交付在 `output/changan-cinematic-tutorial/`。推文富文本可复制并导出，视频附字幕和章节。教学演示查看、切换、滚动和播放；生成、保存、合成按钮只指示其位置，没有为录制再次提交项目媒体任务。录制前后核对项目快照，阻止网页数据修改请求。

最终媒体技术检查、截图检查、排版检查和证据局限保存在交付目录。白蓝用于文章、封面、章节和讲解提示，不改古装影片本身的暖色美术。当前影片仍有剧情节奏待审反馈，教程保留该制作经验。

最终教程约6分12秒，1920×1080、30帧、12章，含普通话合成讲解和中文字幕；末尾两段现有影片保留原对白。推文约3100中文字、14张制作图片。

交付入口为 `output/changan-cinematic-tutorial/index.html`，可切换推文与视频、选中正文、复制富文本、导出HTML、放大图片和跳转视频章节。`推文与视频教学-白蓝发布包.zip` 收集文章、视频、字幕、讲解稿、图片与质检记录，不包含私有项目快照、登录资料、API回执或签名素材地址。

复核命令在项目根目录运行。录制依赖已运行的工作台与现有合法会话、原媒体存档；不用重启服务。

```powershell
python -X utf8 docs/tutorials/changan-cinematic/review.py final
python -X utf8 docs/tutorials/changan-cinematic/review.py narration
python -X utf8 docs/tutorials/changan-cinematic/review.py editorial
```

`produce.py check` 执行完整文件解码和技术检查，重新构建包；之后需按实际复核范围更新人工抽帧记录，再运行 `review.py finalize` 汇总证据与打包。不要把抽帧、自动识别或解码成功写成完整人工试听、口型与剧情节奏验收。
