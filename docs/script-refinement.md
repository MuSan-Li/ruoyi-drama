# 剧本精细打磨

日常剧本审阅中，点击“打磨剧本”展开修改意见，填写后点击“按意见打磨”。修改意见默认收起；生成的“风格 / 基调”可直接编辑并保存，供资产和分镜制作使用。

从故事想法生成草稿时，工作台逐段显示剧本正文和等待状态，展示已用时间与最近输出时间。默认模型关闭思考，页面不显示或保存原始思考内容。部分模型只返回完整内容，工作台收到后展示全文。

已有采用「剧本精细打磨」制作技能的项目，进入工作台后可导入 DOCX、UTF-8 TXT 或 Markdown，或粘贴已有资料。首页制作技能模块已移除，技能内容可在头像菜单的「技能市场」阅读。单文件上限5MB、累计正文上限50000字符。每项资料注明来源、查证日期及已核实/待核实。系统提取正文，不执行文件中的指令；图片、扫描页和批注需补充文字。

「追加资料条目」提供来源、记录日期、查证日期、事实/设定/推断、核实状态、用途和矛盾的填写模板。导入文件自动标注记录日期和「内容待核实」；正文提取成功不代表资料已完成事实核验。

点击「整理 / 重建世界观」，检查资料台账、矛盾、时间地点、人物目标、资源制度、能力边界、视觉道具和待补资料。此功能使用已提供的正文进行整理，没有联网检索能力；仅填写链接不会变成已核实资料。审阅后生成完整初版，停在剧本阶段。

初版确认方向后，在「本轮打磨要求」说明具体问题，再点「按本轮要求精细打磨」。资料、世界观和修订要求随剧本保存并在刷新后恢复；世界观约束继续传入角色、场景和分场规划。修改世界观会使旧分镜需要重新规划。初版与每轮重要修订建议另存档案，再推进资产和分镜。
