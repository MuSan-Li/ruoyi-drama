# GitHub 短剧技能

技能市场与后台制作技能共用实际分类目录。首页头像菜单进入“技能市场”，按编剧风格、导演风格和视觉风格阅读；系统提示词和默认制作技能仍单独展示。剧本与分镜页面只选择编剧、导演风格，每类最多一项；视觉风格移到资产配置中选择。

本次接入十个仓库，整理十五个项目适配技能。ZenStory 剧情组织、说好改编和微短剧人物分集归编剧；故事转分镜、Seedance 多模态提示词、一致性续段、摄影表演和案例方法归导演；电影写实、三维 CG、二维手绘、漫画运动、动漫动作及影视风格方法库归视觉。来源登记和参考资料仍保留在各技能中。

后台“智能体管理 → 技能管理 → 制作技能”使用同一分类筛选和编辑。分类来自 `/short-drama/skills/categories`，技能来自实际运行目录，前端不维护一份静态热门列表。保存沿用内容版本校验并回读；后台编辑过的同名技能不会被打包初始内容覆盖。

编剧使用原 `storyboardSkillNames` 字段保存一项，导演和视觉分别使用 `directorSkillName`、`aestheticSkillName`。剧本写作只加载编剧风格，分镜规划加载导演风格，资产出图加载视觉风格。默认业务流程另外按阶段读取三份精简方法，覆盖改编证据、镜头接点与最小返修。技能版本参与规划缓存，已批准媒体保留。

上游有逐秒提示词、固定集长、强制首帧和平台参数的地方，已按项目规范适配：导演正文连续叙述，时长在 timing，首帧按需使用，模型参数读取当前供应商配置。维护脚本不自动执行，技能导入不提交媒体任务。生成状态、字段检查与实际画面声音验收分别记录。

分发源、固定提交、许可范围及维护命令见[技能适配包](../skills/github-short-drama/README.md)。许可明确的七个仓库保留入口快照，另外三个仅保留来源登记和自主方法；这些快照不是已安装的完整 Agent 技能。
