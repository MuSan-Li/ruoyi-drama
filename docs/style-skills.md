# 审美与导演技能

首页不再展示制作技能模块；新项目在剧本生成时自动整理“风格 / 基调”，作者在剧本审阅中维护该方向，资产分析和出图读取已保存内容。旧项目的审美、导演技能绑定与已批准素材继续保留。头像菜单中的“技能市场”只读展示实际短剧系统提示词、默认制作技能、后台审美与导演风格，可查看正文、内容版本和附属参考；通用智能体及个人技能不在市场中展示。

尚无分镜的项目在资产配置阶段选择「分镜方式」；点击生成分镜时自动保存并回读项目绑定，无需单独保存绑定。下拉列表来自后台实际启用的导演技能，默认方式不依赖可选列表加载成功；新选自定义方式仍须核对启用状态。列表读取失败由选择器本地处理，不把可选列表故障显示成默认方式报错。已有分镜的项目不再显示技能绑定区域，已有素材操作不依赖页面列表读取，业务接口继续校验实际项目方向及内容版本。技能说明显示正文和附属参考；已有图片、视频保留。

「专业分镜 · 重点清楚，镜头连贯」使用 [专业分镜规则](../skills/cinematic-storyboard/SKILL.md)：每个镜头先说清楚要让观众看到什么，再安排怎么拍；前后镜头的动作、道具和移动方向要接得上。默认分镜业务流程也加载此规则；项目可绑定后台维护的版本。它只在分镜阶段设计镜头，不在生成剧本时添加独立的摄影规则或摄影指导。参考来源见 [LibTV 技能登记](../skills/cinematic-storyboard/references/libtv-sources.md)。

在后台“智能体管理 → 技能管理”的制作技能分类维护名称、描述、类别、启用状态、Markdown正文及 `scripts/`、`references/` 下的文本文件。列表使用后台搜索、筛选与表格，阅读和编辑在详情弹窗中展开，正文支持阅读、Markdown编辑和并排对照。技能标识创建后保持稳定，更新使用内容版本防止覆盖他人的修改；未保存草稿在关闭和切换时提示。脚本在本流程中仅保存和查看，不自动运行。

菜单统一到 `/agent/skills`，原 `/short-drama/skills` 地址保留兼容。通用技能分类展示现有 `/agent/agent/skillOptions` 返回的名称和描述，只读查看；其磁盘目录、智能体关联名称及聊天加载方式保持原样。通用技能读取与制作技能维护分别沿用既有权限，不因合并页面扩大权限。

审美正文写人物比例、服饰形制、材料光泽、色彩与空间标准；导演正文写叙事重点、表演、机位、镜头节奏与声音。附属参考记录原始URL、年代地域范围、读取程度、许可与局限。公开馆藏页面不代表图片再分发授权，GitHub渲染资料不能证明服饰史。禁止仅堆“精美、8K”替代可审阅造型决定。

技能内容版本参与规划缓存与提示词；修改技能后应重新审阅受影响的规划和候选图。默认输出结构、原对白、0秒首态、连续性与实际人数规则继续生效。缺失或停用绑定会明确提示重新选择，生成不会悄悄套别的技能。用户确认前，新审美图只作为候选。

写作和规划模型读取正文及参考资料；每个参考文件最多20000字符，全部参考最多60000字符，超限先提示精简。直接图片/视频提示词只带审阅后的方向正文，不展开许可登记、长参考文献和维护脚本，版本仍对应完整技能包。审美基础画风留空时采用正文定义的自定义方向，避免强加旧项目的真人写实材质。

运行目录默认 `ruoyi-ai/data/short-drama-skills/`，可用 `short-drama.skill-directory` 配置；备份应包含整个目录及隐藏历史版本。打包内初始技能仅在同名目录不存在时写入，不覆盖后台已编辑内容。项目保存 `aestheticSkillName`、`directorSkillName`；通用智能体技能勾选保持独立。

本机资产审美技能的可维护源在 [skills/short-drama-asset-aesthetics](../skills/short-drama-asset-aesthetics/SKILL.md)。它指导检索、审图与维护；项目实际采用的是后台所选技能正文。原有剧本和已批准媒体不是因技能升级自动失效或被覆盖。

成熟国漫方向使用 [国风半写实 · 明代历史 CG](../skills/ming-historical-semi-realistic/SKILL.md)，其完整视觉规范涵盖演员骨相与五官、皮肤与发束、服饰器物材料、色板、空间、光影以及各景别验收。附属资料包含风格来源、制作规范、提示词模板和项目演员矩阵；当前剧本案例仅用于对应项目。基础画风留空，由正文定义成熟国漫CG，避免旧标签的卡通形容词混入。人物面部母版与完整全身服装图分图生成，用户批准的场景保留；新人物仍先作为候选，不自动替换跨集身份。

角色参考共用生成路径支持明确的“单幅头肩面部母版”“单张面部肖像”等用途，不再强制其变成全身或多视图；仅在人物描述中提到面部细节不会改变原有全身模式。原图100%查看眼睑、虹膜、眉毛、鼻唇与发际线，不能用全身小脸的放大图或2K标签代替清晰度审阅。

明确要求主角精致时，制作技能须给出轮廓、主辅配色、领袖与下摆层次、适合场合的帽发、精工装饰区和固定配件；避免将克制理解为普通群众素袍。官帽视事与露髻发饰按服装版本分开，具体精工材料对应成长阶段；全身图与头肩细节图分别验收。项目案例及来源范围在 [主角妆造参考](../skills/ming-historical-semi-realistic/references/protagonist-costume-design.md) 维护，用户选择前保留原演员和服装版本。

后台已维护的五个初始技能有一份 [源码快照](../skills/short-drama-asset-aesthetics/catalog-snapshots/README.md)，包含正文、清单、参考资料和脚本文件，便于版本管理与分发。运行目录仍是当前内容的来源；更新快照前先核对后台版本，不覆盖未同步的编辑。

上美影二维动画使用项目适配的 [故事与分镜技能](../skills/smy-seedance-storyboard/README.md) 和 [造型与色盘技能](../skills/smy-animation-aesthetics/SKILL.md)，后台标识分别为 `smy-seedance-storyboard`（导演）与 `smy-animation-aesthetics`（审美）。上游提交、原文和内容哈希保存在导演技能源目录；运行目录通过现有目录API维护并回读版本。单剧选择手绘平涂、水墨淡彩、剪纸、敦煌重彩或石蓝淡墨绘本中的一种，不修改全局默认及旧项目。水墨淡彩允许墨色浓淡和浅彩过渡；不得套用手绘平涂的绝对无渐变命令。连续导演描述、独立timing、首帧可选和实际成片审阅规则继续生效。

Seedream 4.7 使用精确型号 `bytedance/seedream-v4.7/text-to-image`；新角色参照为2496×1664，16:9场景使用官方2K预设2848×1600。这个型号不接受参考图片，系统不会替换成编辑型号。带身份/场景参考的连续性生成应另选可接参考图的模型；对无图文本候选逐张审阅，不宣称已经锁脸。


### 分镜前管理固定道具

固定道具与角色、场景一起在资产配置阶段建立，不依赖分镜先存在。进入“道具与镜头资产”填写道具名与外观描述即可保存，镜号可留空；待分镜完成再关联真实镜号。同名编辑留空时保留已有镜号，填写不存在的镜号会拒绝保存。剧本变更不阻止维护固定道具；无分镜时可独立生成道具图；有分镜后的规划与生成仍需通过当前剧本检查。保存资产卡仅记录描述，图片生成是独立操作。

分镜下方的“参考图”同时展示所选角色形象、场景与承接信息 `visible_props` 中绑定的已生成道具，并标明类别和名称。道具图片通过项目媒体预览读取；点击缩略图可放大查看。明确为空的 `visible_props` 不附带其他镜头的道具；绑定道具尚未就绪或读取失败时显示提示，可点击“刷新参考图”重新读取。查看参考图不会提交图片生成任务，也不会修改原资产和分镜。
