# 镜头资产与生成恢复

资产按用途分层：人物形象锁定身份和服装；场景参考锁定建筑空间与时段；道具参考锁定反复出现的实物；每个已确认分镜再生成一张独立起始关键帧。

操作顺序：确认剧本和分镜 → 资产配置中的“分析镜头资产” → 检查道具与镜头清单 → “生成缺失资产 / 重试失败” → 放大审阅画面、查看对应分镜 → 人工确认后才生成视频。原有人物和场景图片不因分析逐镜资产被删除。

默认图片模型为 Atlas `openai/gpt-image-2.5-flare/text-to-image`；需要角色、建筑、道具参考时自动选择 `/edit`。服务端模型配置必须同时包含这两个型号，并配置可用 Atlas 连接。2.5 参数使用原生尺寸：16:9 为 1536×864，9:16 为 864×1536；最多 16 张有顺序的参考图。

道具先生成，再以最多 4 路并发生成镜头图。任务 ID、结果、失败原因保存在数据库，刷新页面不重新提交任务。已确认任务查询超时进入“等待结果”，继续时查询原任务。明确失败才能新建任务。完成状态仅代表取得图片，并非视觉审阅合格。

修改人物、场景参考、分镜画面描述或承接状态后，应重新分析资产。来源摘要发生变化的镜头会变为待生成；未变化的成品保留。视频生成会优先使用与当前分镜匹配的起始关键帧，过期关键帧不自动传给视频模型。

分镜规划按场景最多 3 路并发，汇总时仍按故事顺序编号；失败保留已完成场次的 7 天缓存。首个输出及无输出等待上限缩为 90 秒，单批上限 8 分钟，并发送进度心跳。分镜细化每批最多 8 镜、最多 3 路并发。模型服务排队与执行耗时仍取决于提供方。

数据库迁移位于配套后端：`docs/script/sql/update/2026-09-30-short-drama-visual-asset.sql`。新表保留租户隔离，异步线程继承请求租户。

清晰账页、表格、软件屏幕应继续使用已取得的真实素材进行后期替换，不能用生图模型编造的文字代替证据内容。

## 剧本与分镜的职责

大纲只写节奏、因果和情绪转折；正文写主要行动与必要对白。摄影、照明、人物站位、手部动作和逐秒表演安排在分镜展开。简洁且结构完整的剧本不因字数少或场数少而自动扩写。

场次标题可标注“预计60秒”。分镜规划逐场校验预算，允许10%的制作估算误差；每镜1至15秒，短镜头不会被强制拉长到5秒。超出预算时先合并可连续完成的动作，不通过加速对白或动作凑时长。

预算校验未通过时，下一次调用只针对该场的已有方案修订时间和表演；并发批次中的其他场次继续完成缓存。校验失败不会覆盖当前已保存分镜。

修改正文后，旧资产保留并提示需要重新规划。停止旧版批次后，“仅恢复已提交任务”只查询已经取得任务ID的结果，不新建剩余图片。单张关键帧构图有误时，可用“修正构图”独立重生；生成完成仍需人工审阅。

## 真实屏幕与账页

在对应分镜的“使用真实素材”中上传PNG或JPEG。原图保存在本机后端，绑定到镜头后可预览，刷新页面仍保留。此类镜头不进入生图和AI视频重绘，剪辑时按该镜预算插入原图。替换文件会保留旧文件。镜头正文修订后，受影响的旧关键帧退出当前使用，未变化的图保留。

### 多张真实素材

分镜中的「添加素材」支持一次选择多张 PNG/JPEG，追加到现有素材之后。每张图片可独立更换或移除；更换保留该图的用途说明，移除只解除镜头绑定。每镜最多 20 张，单张不超过 10MB，单次总计不超过 19MB，可分批追加。


## 固定道具、参考音频与前十镜试片

资产配置中的“维护固定道具”可设置名称、外观、使用镜号，也可上传既有参考图。人工维护的道具不会被后续 AI 分析覆盖。镜头生成除人物、建筑外，同时接收当前镜头可见的道具图片与外观说明。

分镜承接信息支持 `keyframe_directive`（经过审阅的起始构图修订）及 `composition_reference_urls`（最多两张已上传的相邻镜头构图参考）。构图修订必须与起始状态相容；完整动态、台词和结束状态仍由视频提示词表达。

“生成前10镜资产”和“生成前10镜视频”用于先制作开场试片。批量视频开始前检查相关关键帧；真实素材镜头单独点击“生成真实素材片段”，按绑定顺序展示原始截图，并参与成片合成。真实素材视频可直接在项目中预览。

分镜确认 → 展开顶部工具 → 参考音频与背景音乐：

- **背景音乐**：设置使用镜号、音量、素材起点，合成时混入；连续镜头共用一段音乐，淡入淡出，对白出现时自动压低音乐。
- **生成参考**：把音频绑定给指定镜头，提交给支持参考音频的生成模型。它用于音色、语气或节奏参考，不等于原声逐采样复制；原曲配乐应使用背景音乐用途。

音频单文件上限19MB，处理长度最多10分钟。原始上传转换为48kHz立体声MP3，保存在项目后端本地数据目录；试听需要项目访问权限。参考音频在该镜开始生成时上传给已配置的模型服务。生产部署应持久化 `data/short-drama-sounds` 和 `data/short-drama-materials`。

已审阅关键帧进入视频阶段时，优先作为唯一画面依据。人物、场景、道具参考先在关键帧中融合，避免视频阶段再次引用原始设计图，造成镜头换机位、道具重复或摆放提前。显式选择的多参考图模型即使只有一张图片，也保留该模型以支持音频参考。对应模型缺失时停止提交并明确提示，不自动退回文生视频。

生成参考音频限制为2至15秒，每镜最多3条、合计不超过15秒。背景音乐仍可使用更长素材。真实素材条目可设置 `crop: {x,y,width,height}`，数值为0至1的原图比例，仅在视频渲染中裁切，原图保持不变。

分镜支持“导入修订视频”，用于屏幕跟踪合成等外部精修结果回填。上传限制19MB、最大4K，须有音轨，时长与镜头预算误差不超过0.25秒。正在生成或合成时不允许覆盖；旧文件保留，新片段与其他镜头一同参与成片合成。
